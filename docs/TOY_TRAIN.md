# Toy Train — fourth Toy Shop board

A forest-green locomotive and coal tender share a visible coupling. The engine
shell carries its boiler roof and chimney. Removing it reveals the boiler plate;
removing that exposes the drive-gear carrier. Tender body and coal leave together.
Six fixed wheels retain the toy's recognizable silhouette as its panels release.

18 screws / six removable assemblies / two free trays. The color/dependency pattern
matches the accepted robot planning puzzle; this is a new shape and theme object,
not a claimed increase in logical difficulty. Radio, Car and Robot are unchanged.

The Toy Shop adds a fourth card. In landscape, scroll down for the fourth toy.
Next Toy now proceeds Robot -> Train -> Radio. All build commands include all five
scenes (shop plus four boards). The shared build scene list includes Train too.
Train has independent completion and resume keys, existing boards keep their saves.

PC/phone acceptance: open Train, rotate to every face, solve without bonus trays,
inspect both inner layers, restart mid-removal, resume, verify the completion card
and return to the shop. Use a new full Android build to include the new scene.

Validation: nine gameplay/navigation/capture checks passed. A separate shop preview check passed and portrait layout was visually reviewed. No Android device acceptance is claimed; rebuild and test on phone.
