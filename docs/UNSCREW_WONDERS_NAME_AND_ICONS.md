# Unscrew Wonders: preliminary name screen and icon concepts

Checked 2026-10-20. Working candidate only; no app rename or production icon change.

## Preliminary findings

- Exact-name general web searches and indexed Google Play / Apple App Store searches did not surface an exact-name game. This is limited to indexed results, not exhaustive storefront availability. The direct Google Play search was inaccessible through the web tool.
- USPTO live search UI, Field tag and Search builder mode, query `CM:"unscrew wonders"`: "No results found". No class restriction.
- The broader Wordmark search returned related terms, including UNSCREW FAMILY (99788276, displayed LIVE REGISTERED, downloadable computer games), UNSCREW NUTS SORT (98863529, displayed LIVE REGISTERED, mobile game software), and UNSCREW FRENZY 3D (99825211, displayed LIVE PENDING, mobile game software). These are leads for similarity review, not a conclusion of conflict or clearance.
- WIPO search could not be completed because the site presented a challenge. International, state and common-law clearance is incomplete.
- Recommendation: keep developing the candidate visually; obtain a fuller similar-mark clearance in intended launch markets before committing to publication. An empty exact-name search does not establish legal availability or guarantee store search ranking.
